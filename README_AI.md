# UjinFizteha — React, React Bits, Telegram и MCP

## Запуск

Нужны Node.js 22.12+ и Python 3.8+. В корне репозитория:

```bash
npm ci
npm run build
python app/run.py
```

Откройте http://127.0.0.1:8787/web/. Python раздаёт собранный React из
`app/web/dist`, дополнительных серверов в production-режиме не требуется.
Без сборки сервер возвращает сообщение с командой `npm run build`.
Для доступа в доверенной локальной сети добавьте `--host 0.0.0.0`.

Для разработки запустите Python на порту 8787 и отдельно `npm run dev`.
Vite проксирует `/api` к Python. React-исходники находятся в `frontend/src`.
Обновление `frontend/src` требует новой сборки для Python-сервера.

## Новый интерфейс

Тёмный dashboard, три главных раздела: «Мой дом», «Сценарии», «История».
Четыре эмулятора: умная розетка, свет, термостат и вентиляция.
Настройки открываются по изображению устройства. Включение и выключение
применяется сразу; настройки и сброс защиты также выполняются без подтверждения. Фильтр
Rubber Segment показывает устройства по комнатам. Squish Switch блокирует
повторные команды во время выполнения запроса.

Slosh Gauge в настройках устройств управляет яркостью света и шестью
ступенями скорости вентиляции. Изменение скорости переводит вентиляцию в ручной
режим. Настройки сохраняются автоматически: числовые поля и регуляторы — с короткой
задержкой, выбор режима — сразу. На выключенном оборудовании регуляторы недоступны. Выключенные термостат
и вентиляция не обновляют показания датчиков: до включения видны последние измерения.

Сценарии поддерживают создание, редактирование нескольких действий, удаление,
включение и изолированный прогноз на 30 секунд. Правила сохраняются в
`app/data/scenarios.json`; показания и события хранятся в памяти текущего запуска.

Новый конструктор — `frontend/src/components/ScenarioSheet.tsx`: shadcn/ui Sheet,
Glide Select, Scrub Field, Squish Switch и Animated List из бесплатного React Bits.
Он использует прежний API, поддерживает несколько действий, точный ввод,
валидацию, проверку сценария и создание в выключенном состоянии.
Для включения и выключения используются понятные подписи вместо 0/1.
Панель управляет фокусом, поддерживает Escape и полноэкранный мобильный режим.
Tailwind подключён без глобального preflight; общая тема — `premium.css`,
шрифт Play поставляется локально. `npm run typecheck` проверяет новый TypeScript.

Лаборатория находится под кнопкой настроек в шапке: перегрузка, повышение CO₂,
вечерний режим и сброс состояний. Всё работает на эмуляторах.

После перегрузки откройте розетку: установите `Нагрузка = 900`, примените,
сбросьте защиту, затем включите розетку. Защита не сбросится, пока нагрузка
превышает лимит. При необходимости можно сбросить все эмуляторы в лаборатории.

Для телевизора: `/web/?mode=tv`. Поддерживается навигация стрелками и Enter.
APK-обёртки пока не созданы. Авторизация для публичного сервера пока не реализована.

## React Bits и MCP реестра компонентов

В проект добавлены исходники из официального реестра React Bits. Числа анимирует
CountUp; единственный общий WebGL-фон — DarkVeil; карточки подсвечивает SpotlightCard.
При `prefers-reduced-motion`, экономии трафика или слабом устройстве фон заменяется
статическим градиентом. DarkVeil приостанавливается в скрытой вкладке.
Фото устройств находятся в `frontend/public/images/`, описание генерации — рядом.

Реестр `@react-bits` прописан в `components.json`. MCP-сервер shadcn настроен в
`.mcp.json` для совместимых клиентов и локально в Codex:

```bash
codex mcp add shadcn -- npx -y shadcn@latest mcp
npm run mcp:check
```

После изменения настроек перезапустите Codex, чтобы инструменты загрузились
в новую сессию. `mcp:check` независимо выполняет настоящий stdio handshake,
запрашивает список инструментов и ищет CountUp в React Bits.

Инструкции: https://reactbits.dev/get-started/mcp и https://ui.shadcn.com/docs/mcp.
Лицензия компонентов приложена в `frontend/src/components/reactbits/LICENSE.md`.
Для совместимости сборки используется WASM-версия Rollup, зафиксированная в lockfile.

## Telegram

```bash
export TELEGRAM_BOT_TOKEN='...'
export TELEGRAM_ALLOWED_CHAT_IDS='123456789'
python app/run.py --telegram
```

Поддерживаются `/status`, `/events`, `/scenarios`, `/demo`, `/help` и inline-подтверждения.
Реальные токены не добавляйте в git. `.env.example` — только шаблон; загрузите
переменные в окружение перед запуском (автоматическое чтение `.env` не реализовано).

## MCP умного дома

Это отдельный сервер от shadcn MCP: он предоставляет агентам состояние и команды
Power Guardian. Требуется Python 3.11+ и зависимости из `requirements-mcp.txt`:

```bash
pip install -r requirements-mcp.txt
python app/run.py --mcp
```

Текущий `--mcp` создаёт отдельный экземпляр дома, не подключается к уже работающему
HTTP-процессу. MCP-пакет не требуется для web и Telegram.

## Проверки

```bash
npm run build
npm run typecheck
python -m unittest app.tests.test_power_guardian
python -m unittest discover -s task/quattrocold/emulators/tests
npx playwright install chromium
npm run test:e2e
```

Если Chromium Playwright не установлен, но есть Edge, в PowerShell можно выполнить
`$env:PLAYWRIGHT_CHANNEL='msedge'` перед `npm run test:e2e`.

Браузерный тест поднимает отдельный runtime без файлового хранилища. Проверяет
изображения, управление, перегрузку и восстановление розетки, создание/симуляцию
правила, комнаты, мобильную компоновку и TV-навигацию.
