# Уведомления устройств

События формирует `app/device_notifications.py`, который вызывается общим
Orchestrator после команд и шагов эмуляторов. Веб, Telegram и MCP получают
одни и те же записи. Состояние API содержит `notification_protocol: 1`;
это позволяет клиентам отключить собственное повторное вычисление тревог.

| Устройство | События |
| --- | --- |
| Умная розетка | Включение/выключение, таймер, перегрузка, аномалия, восстановление, настройки |
| Основной свет | Включение/выключение, автоотключение, яркость и настройки |
| Термостат | Режим, цель, достижение температуры, неисправность и восстановление |
| Вентиляция | Режим и ручная скорость, цель CO₂, высокий CO₂ и восстановление |
| Датчик температуры | Сбой, низкий заряд, вскрытие, восстановление, настройки |
| Датчик протечки | Протечка и её устранение, заряд, вскрытие, самотест |
| Хаб протечки | Протечка, сирена, потеря/возврат датчиков, заряд, отключение звука |
| Пожарный датчик | Пожарная тревога, сбой, заряд, вскрытие, восстановление, настройки/самотест |
| Счётчик | Реле нагрузки, связь, заряд, высокий уровень мощности, восстановление, настройки |
| Телевизор | Включение/выключение, таймер, сбой и восстановление, громкость/источник/прочие настройки |
| Холодильник | Режим, открытие/закрытие двери, температурная/дверная тревога, сбой, восстановление, настройки |
| Чайник | Начало нагрева, готовность воды, ручная остановка, сухой ход, очистка, настройки |
| Плита | Включение/выключение, таймер, перегрев, отсутствие посуды, восстановление, настройки |
| Духовка | Включение/выключение, завершение таймера, окончание прогрева, дверь, тревога/сбой, восстановление, настройки |
| Домофон | Вызов, ответ/завершение, открытие/закрытие двери, отклонённое открытие, вскрытие, настройки |

## Формат

Запись, предназначенная для показа, содержит:

```json
{
  "type": "alarm",
  "device": "fire_1",
  "signal": "alarm",
  "value": 1,
  "previous_value": 0,
  "source": "device",
  "title": "Пожарная тревога",
  "kind": "error",
  "message": "Пожарный датчик: Пожарный датчик сообщает о задымлении. Причина: ЕСТЬ.",
  "notification": true,
  "watch_key": "fire_1:alarm",
  "category": "safety"
}
```

`id` и `time` добавляются журналом. `kind` принимает `info`, `success`, `warning`,
`error`. Тревоги имеют тип `alarm`, восстановление — `device_recovered`, операции
и настройки — `device_notification`, завершение — `device_finished`. Существующие
события чайника `device_started`/`device_stopped` сохранены.

Сырая запись команды остаётся в API для аудита с `notification_handled: true`.
Она не показывается повторно рядом с сообщением о фактическом результате.
Категории `safety` и `commands` используются фильтрами истории на сайте и в боте.

## Защита от повторов

- Сохраняются переходы состояния, а не каждое измерение температуры, энергии или мощности.
- Повторное значение и повторный опрос не создают новое сообщение.
- Короткая тревога и восстановление между опросами читаются из журнала.
- CO₂: тревога при значении выше 1000 ppm, восстановление при 900 ppm и ниже.
- Мощность счётчика: тревога выше 6000 Вт, восстановление при 5500 Вт и ниже.
- Термостат сообщает о достижении цели один раз на режим/целевую температуру.
- Повторные циклы поддержания тепла чайника не рассылаются как новые включения.
- Штатные циклы компрессора холодильника не создают уведомлений.
- При загрузке сайта актуальные проблемы показываются один раз; старые события не воспроизводятся.
- При запуске Telegram старые события не рассылаются; подписка включается через `/start`
  или меню `/notifications` и сохраняется в локальном состоянии бота.
- Доставка в Telegram идёт пачками до 12 событий с фотографией устройства либо общего дома.
  При временной ошибке пачка повторяется только для неуспешного получателя.

Очередь повторной доставки пока хранится в памяти бота. Общий журнал ограничен
200 событиями; длительный архив и долговечная очередь доставки требуют отдельного
хранилища. Наличие уведомления о тревоге не означает наличие защитного сценария:
фактические действия зависят от встроенной защиты и сохранённых правил.
