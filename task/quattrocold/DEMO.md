# Демо-скрипит для жюри (5–7 мин, preprod)

> **Твой стенд: тест-ОАЭ** (API `https://api-uae-test.ujin.tech/api`). Все адреса в этом документе уже переведены на него; где осталось слово «preprod» (история прогонов) — читай «тест-ОАЭ». Устройства: команда запуска в брошюре (`--ust-auth`), dev-токен не нужен.

Подготовка (за 10 мин до): панель http://127.0.0.1:8091 жива (`/healthz`),
`token.txt` свежий, эмулятор judge запущен, экран — только панель.

1. **(60 с) Картина.** Панель → главная: LIVE-таблица — 2 устройства
   (judge-датчик + judge-шлюз) обновляются каждые 2 с.
   Слова: «это живые данные preprod, не картинка».
2. **(90 с) Одно семейство вживую.** Карточка leak-датчика: секции
   📊 свойства / 🎛 возможности / ⚙️ настройки, русские имена, sparkline.
   Кнопка `wet=1` (task) → через пару секунд `leak=1` у шлюза + сирена.
   Слова: «физика внутри эмулятора, платформа — как настоящее железо».
3. **(60 с) История.** `/history` по сигналу: кривая суток (архив БД).
4. **(90 с) Генератор.** Терминал: `python new_device.py valve --title "Приток" --clone ventilation`
   → за 20 секунд новое устройство с декларацией → `--live` → оно в панели.
   Слова: «новое устройство — минута, не день».
5. **(60 с) WS.** `python tools/ws_check.py` из корня репо (нужны наши креды)
   (или лог live_loop `wss=empty` + слайд контракта): показать, что контракт
   МП разобран и клиент готов — ждём привязку устройств от орг-ов (fix №11).
6. **(60 с) Харнесс.** `behave quality/features` — 87 сценариев зелёные (dry; live-прогон 94, 29.10):
   «приёмка автоматизирована, регресс ловится до демо».
7. **(30 с) План.** Слайд: порты на другие языки (гайд готов), провижининг
   команд, сценарные IKEA — ждут ответов орг-ов (open-questions D).

Запас (если спросят): `--resource heat` счётчик; fire/ventilation за 20 с
через генератор; open-questions.md — «мы знаем границы системы».

  alexa отвечает 502. Пункты демо про ГЗ/голосигнал — только preprod.
- П.5 (WS) пропустить: `devices/wss/` пуст и там (замер 29.10), статус — R-37.
- Рабочий каркас демо на uae: квартира + панель орг-ов + публикация сигналов
  (когда пробиты блокеры R-31/R-32/R-33). Пока они не сняты и live-прогон
  uae (R-38) не зелёный — **жюри ведём на preprod**, uae не показываем.

Не показывать: пароль панели при вводе; token.txt; имя аккаунта-владельца.
