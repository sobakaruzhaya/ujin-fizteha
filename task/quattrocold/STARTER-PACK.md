# STARTER-PACK — что в пакете команды и как спасать отстающих

> **Твой стенд: тест-ОАЭ** (API `https://api-uae-test.ujin.tech/api`). Все адреса в этом документе уже переведены на него; где осталось слово «preprod» (история прогонов) — читай «тест-ОАЭ». Устройства: команда запуска в брошюре (`--ust-auth`), dev-токен не нужен.

Пакет собирается скриптом на каждую команду (`tools/PROVISIONING.md`),
лежит в `packages/<slug>/`. Всё проверено живьём на preprod 20–22.10.2026
(репетиция + провижининг команд XYZ / Хакатонеры).

## Состав пакета

| Файл | Что внутри | Когда открывать |
|---|---|---|
| `<slug>.pdf` | брошюра: все доступы (3 резидента с ust, квартира, cos-токен, SN+ext устройств, кабинет УК), URL, план первого вечера по шагам | сразу, лучше распечатать |
| `START.md` | шаги 1–7 в формате IKEA, «минное поле» (7 мин), Troubleshooting (симптом→лечение) | день 1, по порядку, не пропускать минное поле |
| `PULL-CLIENT.md` | контракт своего клиента: путь A (опрос кабинета ust), B (HTTP-сервер на устройстве), C (WS — зависит от орг-ов), публикация сигналов вверх | когда пишешь свой код интеграции |
| `SCENARIOS.md` | автосценарии «если — то» (токен резидента), что видно в BMS/МП, контракт виджета консьержа | когда база работает и нужен «изюм» |
| `DEMO.md` | скрипт демо для жюри на 5–7 минут | накануне показа, репетировать |
| `api-methods.md` | справочник ручек: параметры, ошибки, примеры | вместо угадывания API |
| `emulators/` | эталонные эмуляторы 9 семейств + тесты; `python main.py leak --port 8099` | день 1 как копируемый пример |
| клон репозитория (URL у орг-ов) | `ports/` — тот же контракт на ts/go/php/dotnet; `quality/` — приёмка; `protocol-porting.md` | пишешь свой язык/приемаешь проект |
| `доступы.json` | те же доступы машиночитаемо (код читает вместо копипасты из PDF) | в своих скриптах |

Правила пакета: новые ручки не угадывать — смотреть `api-methods.md`;
токены не коммитить — приёмка `quality/check.py` ловит (К-03).

## Протокол спасения: команда не справляется

Порядок: от симптома к запасному плану. Каждый уровень — только если
предыдущий не помог.

1. **День 1, ничего не заводится.** Сверить три главные мины START.md:
   значение `0` платформа не пишет (нужно `0.001`); новый сигнал — двумя
   запросами; поле `c` публикации = класс модели (`integrations_devices`),
   при несовпадении `error=0` и пустота. Проверка за 5 минут: спроси орг-ов —
   покажем значения на нашей панели (она у орг-ов, не в пакете).
2. **«API принимает, но я ничего не вижу».** На preprod у устройств
   `apartment_id=0` (ограничение, fix орг-ов п.11) — кабинеты могут не
   показывать; смотреть через панель. Это не их баг, нервы беречь.
3. **Команда «вниз» не доходит до устройства.** Авто-словари создаются
   `mgmt=r` (только чтение) — даунлинк невозможен, пока орг-и не дадут rw
   (organizer-fixes п.2). Лечится запросом к орг-ам; обходная — через панель
   орг-ов (устройства на `parkcloud_device`), обратись к ним.
4. **Нет времени/навыков писать своё железо.** Разрешаем базой: взять
   `emulators/` как своё устройство и писать логику поверх него. Это
   засчитывается: проверяли полный цикл эмулятор→платформа→кабинет живьём.
5. **Демо нечем показать вообще.** Минимальная проходная линия (15 минут
   работы, делаем вместе с командой): запускаем их экземпляром
   `emulators` → публикуем протечку → показываем значение в кабинете
   резидента (путь A) и на панели → сценарий «протечка → уведомление»
   из `SCENARIOS.md` §1. Команда защищает это.
6. **Авто-сценарии не срабатывают (заявленного фикса п.14 нет на стенде —
   проверено БД 22.10: scenario-флаги false).** Замена, равная по виду для
   жюри: свой pull-клиент путь A опрашивает кабинет и шлёт своё
   уведомление — «устройство → правило → сигнал» на экране, без зависимости
   от платформы.

## Честные границы (не обещаем командам)

- WS-подталкивание (п.11), rw-словари, автосценарии на сценарных сигналах
  (п.14) — на стороне орг-ов, на 22.10 не работают; заменяем путём A.
- Свой дом/квартиру с адресом создать нельзя (админка не умеет) — квартира
  уже выдана в `доступы.json`.
- Прод-контур недоступен: всё тестирование только preprod.
